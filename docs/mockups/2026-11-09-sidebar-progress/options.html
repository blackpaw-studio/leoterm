Sidebar Task Progress

The native Mac pattern beside today's row. A sidebar row gets one small, unlabeled progress indicator at its trailing edge, the way Finder and Mail show sync and transfer work. Percent, status and ETA move to the task popover.

What the row keeps and what moves

The row answers one question: is this agent busy, and roughly how far along is it? The leading symbol shows agent state and stops spinning, because the indicator now carries the motion. The trailing slot shows the elapsed time when the agent is idle and the indicator when a task runs. The detail line is just the task title. Everything else (percent, status, ETA, the other tasks, Dismiss) is one click away in the existing task popover.

Motion stays at today's level or below. Each working agent has one moving element, as it does now, and a determinate pie only moves when progress is reported.
