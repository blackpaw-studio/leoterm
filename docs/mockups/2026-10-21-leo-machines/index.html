Machine picker

First field
Machine sits above Template and drives everything below it.
Default
Context machine (here: opened from New Agent Here… on Dionysus), else last used, else This Mac.
Switching
Reloads templates, environment options and feature gates from the new machine.

Load
Each row carries a one-line CPU/Mem summary, amber from 80%, red from 90%.
