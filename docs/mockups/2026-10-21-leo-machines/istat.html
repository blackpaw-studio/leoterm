Mac sidebar

Capsule cluster right-aligned on the machine header, before the agent count. Dionysus memory is 85% (amber), Hestia is offline, leo-vm reports no stats.

Fill color

Header row

Each metric is a 3-letter stacked label and a 10 × 20 pt capsule. The cluster is 71 pt wide, and the header row grows from 18 to 20 pt to hold it.

States without numbers

Hestia, offline
No capsules at all. The dimmed name, red dot and failure card already say why.
leo-vm, no stats
Kept as dimmed, empty outlines. They hold the column alignment with the other machines and show the machine can report. Omitting them reads like a layout bug next to the machines that have them. The tooltip says "Stats unavailable".

Tooltip

Hover a capsule for the exact figures. The tooltip is open on Dionysus MEM.

Capsule detail at 4×

1 pt border, 1 pt gap, fill radius 3 pt inside a 5 pt outer radius. The label letters are 6 pt heavy caps with 0.2 pt of leading.

3

Spawn sheet: machine picker

Mini capsules replace the "CPU 41% · Mem 85%" text. This Mac is hovered: the blue fill turns white so it stays visible on the selection color.

Reads well?

Yes. Eyes compare four machines faster by shape than by text, and amber on Dionysus is visible at a glance. The cost is losing the exact percentage; the row tooltip carries it.

Text that stays

Hestia keeps "Unreachable" because the row is disabled and the reason matters.

4

iOS machine list

Same capsule at 1.25×, right-aligned in the cell before the status dot. The cell loses the meter row and gets shorter.

Parity

The capsule is the same shape and thresholds as on Mac. iOS has no hover, so exact figures move to the machine detail screen on tap.

Layout

Name, address and status stay on the left. The 1.25× cluster is 89 pt wide. It sits beside the name and address, and the status line runs full width under it, so nothing truncates.
