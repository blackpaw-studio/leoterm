Leo Machines: stats styles

One setting, five ways to show CPU, memory and disk. Flat solid fills only: blue below 80%, amber at 80% or more, red at 90% or more. Static mockup, no app code changed.

A

iOS Machines list

iPhone 17 Pro, 402 × 874 pt. Inset-grouped list, 16 pt margins, one cell layout for every style; only the meter line changes.

B

Mac sidebar machine header

The same four machines in each style. Bars and Numbers need a second row; Capsules and Rings stay on the single header row.

C

Stats style setting

Mac: segmented control in the Machines tab with a live preview. iOS: a row in Settings that pushes to a checkmark list. Click to try it.
